# WebsiteCoDesignMultiAgentSystems

Static project website for the paper **Task-Driven Co-Design of Heterogeneous Multi-Robot Systems**.

Open `index.html` in a browser to view the site. It includes:

- `https://arxiv.org/abs/2604.21894` as the paper link
- `summary.mp4` as the embedded summary video
- `summary-poster.jpg` as the video poster frame from second 1
- `OverviewDiagram.png` as the hero figure
- `interactive_Pareto_fronts.html` as the embedded interactive case-study visualization
