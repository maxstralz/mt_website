Task-Driven Co-Design of Heterogeneous Multi-Robot Systems

This project presents a task-driven co-design framework for heterogeneous multi-robot systems, where robot hardware, fleet composition, planning, and execution are optimized jointly rather than in isolation. Building on a monotone theory of co-design, the framework represents these coupled decisions through modular design problems with well-defined interfaces, enabling the computation of Pareto-optimal system designs under task-specific performance constraints. The approach is demonstrated on search-and-coverage case studies, showing how different robot fleets, planners, and resource trade-offs emerge as optimal across changing task requirements and environments.

Phase diagrams for Case Study I

Phase diagrams show how the resource-minimizing system architecture changes as the required coverage and available resource budget vary.

Each colored region identifies the optimal fleet composition, planner, or battery configuration, while gray regions contain no feasible implementation. Use the controls to choose the budgeted resource, the resource to minimize, and the architectural phase to display. Up to four configurations can be compared at once, and hovering over a region reveals the selected implementation.
